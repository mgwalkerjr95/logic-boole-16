# Fonts of the documents

`../../datasheet.html` and `../../quick-start.html` are set in these three typefaces. Each is under the SIL Open
Font License, version 1.1, and is here unchanged, as Google Fonts serves it (its Latin and extended Latin
parts). They are not part of the project's own licenses.

| Typeface | Used for | Files | Copyright and license |
|---|---|---|---|
| Archivo | Text | `archivo-*.woff2` | [OFL-archivo.txt](OFL-archivo.txt) |
| Archivo Narrow | Headings and large figures | `archivonarrow-*.woff2` | [OFL-archivonarrow.txt](OFL-archivonarrow.txt) |
| Courier Prime | Labels, signal names and code | `courierprime-*.woff2` | [OFL-courierprime.txt](OFL-courierprime.txt) |

`fonts.css` names the files for the pages.
